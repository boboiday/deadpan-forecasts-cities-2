A deadpan weather forecast for a city that does not exist — one line, delivered with a straight face, for the make.fun Deadpan Forecasts bounty.

> In Tarnwick, 41 mm of uphill rain falls by noon, gusts lifting bicycles onto rooftops. Residents must 'tie down anything lighter than a shed.'

Tarnwick gets 41 mm of rain that falls uphill, gusts strong enough to park bicycles on rooftops, and a residents' advisory quoted word for word — absurd, but read exactly like a real forecaster reading off the map.

## Run it

```sh
node main.ts
```

The program prints the forecast line to stdout and writes it to `/output/entry.txt` (mirrored to `output/entry.txt`), validating that it is a single line of 1–160 characters.
